# Personal Growth Homepage — Altyn

A multi-page personal learning record and skill display website built for the Software Engineering course assignment at Huazhong University of Science and Technology (HUST).

## Pages Included
- `index.html`: Introduction, current study direction, and contact details.
- `learning.html`: Personal learning records covering C programming labs, Calculus, Physics, and Linear Algebra, with interactive topic filtering.
- `projects.html`: Skill demonstrations with C code evidence, course lab work details, and an interactive feedback form.

## Technologies Used
- HTML5
- CSS3
- Vanilla JavaScript

## How to Run
1. Download or clone this repository.
2. Open `index.html` directly in any web browser (Chrome, Edge, Safari, Firefox).
3. Use the top navigation bar to switch between the three pages.
